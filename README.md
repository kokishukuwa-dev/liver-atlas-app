# 肝臓アトラス

肝臓を「臓器 → 肝小葉の並び → 1つの肝小葉（ゾーン1/2/3）→ 類洞・門脈域の細胞群 → 毛細胆管と輸送体」の5段階で、回して拡大できる3Dで見るページです。マウスとヒトの切り替えと、正常・総胆管結紮（BDL）・胆石の切り替えができます。

- 公開ページ: https://kokishukuwa-dev.github.io/liver-atlas-app/
- 出典: [references.md](references.md)（解説文の根拠24件）
- 描画: Three.js r128（同梱）、距離関数と Surface Nets で形を作っています。

模式図であり、大きさ・本数は実物の比率どおりではありません。
