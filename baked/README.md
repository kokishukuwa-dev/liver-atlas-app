# Baked 3D Geometries

Generated by `node scripts/bake.js` from `js/levels.js` and `js/sdf.js`.
- `*.bin`: gzip-compressed binary geometry bundles (`LVB2`: Uint16 positions, Int8 normals, Uint8 colors) fetched over `http(s)://`, decompressed with `DecompressionStream`, and cached by `sw.js`.
- Opening `index.html` via `file://` cannot fetch these and falls back to live SDF meshing (slow). Use the published URL or a local server.
