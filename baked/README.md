# Baked 3D Geometries

Generated by `node scripts/bake.js` from `js/levels.js` and `js/sdf.js`.
- `*.bin`: compact binary geometry bundles (`LVB1`) fetched over `http(s)://` and cached by `sw.js`.
- `*.js`: base64-wrapped script bundles loaded automatically when opened over `file://` (e.g. Edge `--app`).
